# Утверждено — не трогать

Здесь перечислены блоки, анимации и решения, которые пользователь утвердил. Этот файл нужно читать **перед любой правкой сайта**.

## Правила
1. Всё, что перечислено ниже, **не правится и не трогается**: ни вид, ни анимация, ни числа, ни порядок, ни тексты.
   Сюда же относятся «попутные» улучшения, рефакторинг и «заодно поправил».
2. Если новая задача требует задеть утверждённое (в том числе глобальная правка: шрифты, токены, отступы,
   общий JS), сначала **спросить пользователя**. В вопросе назвать, что именно в утверждённом блоке изменится.
   Без явного «да» ничего не менять.
3. После любой глобальной правки снять скриншоты утверждённых блоков (desktop + phone, начало/середина/конец
   анимации). Сверить с тем, что было: изменилось только то, о чём просили.
4. Пользователь утвердил что-то новое → сразу дописать сюда: дата, что именно, где лежит в коде.
   Пользователь сам просит изменить утверждённое → делать, затем обновить запись.
5. Если непонятно, утверждено ли что-то, считать утверждённым и спросить.
