# Scenario — DOMA by GUF (v2)

Written before code (`references/scenario.md`), approved by the user before the build.
v2 заменяет v1 целиком: пользователь попросил полный рестарт (2026-09-24) — не устроили визуальное направление,
ритм переходов между блоками, техническая надёжность 3D hero, и затем — сама последовательность блоков. История
решений v1 — `docs/decisions.md`.

**Thesis (the buyer's words):** «Каждый вкус — новый дроп, который срывают со стены».
Номера на упаковке (№01, №02…) уже читаются как язык лимитированных дропов, не просто линейка вкусов.

**Brand object:** линия разрыва — зубчатый край логотипа DOMA остаётся жестом «сорвать слой и увидеть, что под ним»,
теперь это переход камеры и переход между блоками, а не срыв слоя со стены дома — стены в v2 нет.

## Стилистика v2 (зафиксировано с пользователем 2026-09-24)
- **Тёмная product-stage** — студийная тьма, практический свет (фонарь/пасмурный софт, не RGB-glow), 3D банка и
  пачка — главный герой каждой сцены, где они появляются. Ближе к реальному сайту клиента, чем стена v1: `brand.md`
  Ground — чёрный/тёмный бетон замерен с doma.moscow/product.
- **Свой цветовой мир на вкус** (механика взята у MANA Yerba Mate, en.manayerbamate.com, по прямой просьбе клиента —
  см. `docs/references-doma.md`) — при переключении вкуса меняется цвет освещения и окружения сцены: оранжевый
  (Ориджинал), красный (Энергия), зелёный (Тропик), бронза (Персик).
- **Не полное визуальное клонирование MANA** — решено в диалоге (2026-09-24): берём механику цвета на вкус и общий
  дух карусели, не светлую пастельную мультяшную эстетику и не структуру интернет-магазина (каталог/подписка).
- **Дворовая ДНК остаётся, но не буквально** — в голосе текста, в трафаретных номерах вкусов, в зубчатом разрыве.
  Без фото панельного дома, без граффити-тэгов как декора.
- **Точечный акцент, не decorative neon-фон** — уточнено 2026-09-24 по реальным Reels клиента (`../Фото для сайта/IMG_2777.MOV`,
  90 лайков): в момент раскрытия продукта — тонкая скан-линия акцентного цвета проходит через банку/пачку (эхо
  реального rentgen/CT-scan эффекта из ролика, не полный HUD с рамками — это уже читалось бы как generic
  AI-дашборд); на CTA/кнопках — короткий glow-пульс акцентным цветом (эхо «молнии» из того же ролика, не буквальная
  SVG-молния). Остальная сцена — матовые тона, практический свет, как решено раньше.

## Архитектура/ритм v2
**Уточнено 2026-09-24 после разбора `world.js` (Сайт 1, испытанный паттерн этой мастерской):** «единый 3D-мир» на
деле не одна камера, летящая через одну сцену — это один WebGL-canvas на всю страницу, но у каждого 3D-блока своя
независимая сцена/камера, рендерятся по очереди в свою область экрана (`scissor`/`viewport`). Структурно это ближе к
гибриду (изолированные 3D-острова), чем к рискованной единой камере — и уже проверено на клиенте (Сайт 1). Решение
пользователя: строим по этому испытанному паттерну, не по более амбициозной и рискованной версии с одной камерой.

**Жёсткое правило QA (с первого прогона, не в конце):** тестировать переходы только настоящими
`page.mouse.wheel()`-событиями в Playwright, никогда только `scrollTo()`. В v1 синтетический `scrollTo()` показывал
чистую прогрессию 0→1 и проходил QA, а реальный скролл мышью ломал композицию. Прогонять на desktop (1440×900+) и
телефоне (390×844) реальным колесом на каждом чек-поинте фазы 4.

**Порог отката:** если непрерывный мир не держится на реальном скролле — откат на **гибрид**: 3D-острова только в
Hero и «Продукция» на общем canvas, камера едет между этими двумя блоками; остальные блоки — надёжный DOM/CSS;
единый разрыв-переход (GSAP ScrollTrigger, тот же `.tear-mask`-приём) между всеми блоками без исключения.

**Preloader — отложен (решение пользователя 2026-09-24).** Не реализуем в этом заходе; сайт стартует сразу с Hero.
Вернуться к прелоадеру, когда остальные блоки собраны и проверены.

**Дизайн был «скучно» (пользователь, 2026-09-24), не только архитектура.** При вёрстке каждого блока — более смелая
типографика/масштаб и choреография движения, не шаблонные fade-in карточки.

## Choices for the user (2–3 options where the risk is)
Закрыто в диалоге 2026-09-24:
- Визуальное направление — тёмная product-stage + цветной мир на вкус (не дворовая стена) — решено

- Preloader — отложен на потом — решено
