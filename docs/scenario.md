# Scenario — DOMA by GUF

Written before code (`references/scenario.md`), approved by the user before the build.

**Thesis (the buyer's words):** «Каждый вкус — новый дроп, который срывают со стены».
Номера на упаковке (№01, №02…) уже читаются как язык лимитированных дропов, не просто линейка вкусов.

**Brand object:** линия разрыва — зубчатый край логотипа DOMA становится жестом «сорвать слой и увидеть, что под ним»:
стена панельного дома рвётся и открывает банку+пачку, вкус открывается, блоки переходят один в другой тем же надрывом.

## Стилистика (зафиксировано с пользователем)
- Дворовая, постсоветская — не западный глянцевый стритвир
- Поверхность разрыва — **стена панельного дома** (не дверь подъезда, не гараж)
- Граффити и тэги — да, ключевой элемент
- **Без неона** — только матовые уличные тона, свет практический (фонарь/пасмурно), не RGB-glow
- Другие дворовые предметы (лавочка, турник, качели, бордюры) — сознательно НЕ используются; только фон/текстура и типографика

## Продукция — структура категорий
- **Энергетики** (живая, 4 вкуса: Ориджинал, Энергия, Тропик, Персик)
- **Чипсы** (живая, 5 вкусов: Краб, Сметана и зелень, Стейк на гриле, Сыр начо, Сметана и лук) — по решению пользователя «сухарики» на реальном сайте = чипсы, отдельной категории не делаем
- **Мохито** («скоро», плашка-заглушка)
- Запасной слот под будущее (конфеты и т.п.) — категории живут в data-модуле, добавление = правка данных, не пересборка

**Wow-карта (3 сильных момента, не натянуто до искусственных четырёх):**
1. Вход — разрыв стены → банка+пачка вместе (блок 1)
2. Мир — вкусы как дропы, цвет сцены меняется (блок 3)
3. Человек — стена экранов с реальными людьми (блок 5)

Остальные 5 блоков спокойные, читаются без скролл-трюков — ритм не заезжен.

## Choices for the user (2–3 options where the risk is)
Закрыто в диалоге:
- «Сухарики» = чипсы, отдельной категории нет — решено
- Баннер вскрывает банку И пачку вместе (сложнее, чем просто банка-герой) — решено, риск принят
- Форма сотрудничества — простая, без конструктора-ящика — решено
